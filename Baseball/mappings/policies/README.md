# Mapping Policies

- [`modeling-choices.yaml`](modeling-choices.yaml) records approved ontology modeling patterns.

Source-field IRI rules are not shared policy. The active MLB game rules live in
[`../../sources/mlb-game/mapping/iri-policy.yaml`](../../sources/mlb-game/mapping/iri-policy.yaml).

These files are normative project policy. A source mapping change that conflicts with either policy requires an explicit modeling decision rather than an implementation workaround.
