# Runner boundaries for contribution metrics

`runner-boundary-admission.py` is an operational validation component in the
existing NiFi SHACL stage. It implements accepted E1/C1/C2 decisions using
existing ontology terms and graph patterns. It does not transform or amend
source JSON, domain RDF, RML, identity policies or semantic approval records.

The accepted personal-history reconciler must first account for every source
event, operative review, substitution, movement and ending in every half.
Its episode chains supply expected PA-start occupants without interpreting
an omitted `postOnFirst/Second/Third` field as an empty base. SHACL compares
the expected population with the existing PA-start stases and out-count ICEs,
including shared PA/stasis first instants, base artifacts and their sites.
It also checks exact C1 episode membership, focal Persons and half innings,
and requires each runner Out's existing judgment/decision structure.

Source-derived values appear only in census files and SHACL parameters.
Metric values come from the promoted graph's SPARQL bindings. The proof
retains source, RDF, implementation, census, shape and report hashes. Its
promotion loader verifies those hashes and the owning game evidence path;
missing or stale proof cannot admit a score. NiFi retains the proof in the
existing promotion record and supplies it to SQL materialization.

The first contribution adapter admits a complete single attributed PA
consequence: a supported contact path, causal/normative award, or the
batter's supported strikeout Out. It applies B2 coalescence, excludes positive
error/FC/interference credit, and accounts for every movement. Complete
history allows C2 to preserve unchanged runners through that PA. Three
actual outs strand survivors; no Out, stasis or timestamp is manufactured.
Runners who score have no remaining erosion, and a walk-off adds no out.

Independent movement mixed with the PA consequence remains withheld until
its immediate boundary and separate contribution are admitted. A strikeout
and caught stealing alone never establish a called hit-and-run. Therefore
the real reference game's PAs 12, 23 and 40 remain explicit adapter gaps,
not missing source data or available zero scores.

The resulting inputs serve Contribution, Runner Out Rate, Runner Loss per
PA and Scoring Opportunity Lost. PAQ and PAQ-A additionally require the
complete independent reference-season schedule and every game's admitted
inputs. Empty Game Damage admits only the narrower games where every turn
is covered and no separate independent damaging episode is omitted; it
averages Empty Games only. Other selected games withhold that producer.

Focused proof: `tests/prove_contribution_inputs.py`, with an existing validated
RML manifest and immutable input. It runs owning SHACL, canonical Jena
extraction and exact SQL round-trip without promoting or rebuilding a corpus.
