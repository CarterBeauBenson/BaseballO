# Presentation of all 20 settled metrics

The dashboard now organizes the suite into six perspectives and gives every
measure a label, question, plain-language explanation, reading guide, reported
unit, scope and reference. Technical names remain searchable aliases and are
retained with stable IDs in the detail disclosure. Worked examples use the
same presentation vocabulary.

The complete [name and presentation guide](../../../web/METRIC-NAMING-REVIEW.md)
records all 20 labels, including retained names. The
[worked guide](../../../web/metric-worked-examples.md) explains each measure.

All 20 live metric results—including exact fractions, supporting evidence and
coverage—match the earlier August 25 dashboard capture exactly. The calculation
fingerprint also matches. Display labels and explanatory units do not alter
formulas, numerical units, eligibility, reference populations or SQL products.

The 24 Node checks passed, including a comparison of every analytical contract
field before and after presentation composition. The live browser check passed
for all 20 reading guides, six perspectives, old-name search, shared results,
exact card details, stale requests/downloads and mobile overflow. The nine-run
presentation fixture remains separately identified as a validated local RDF
proof, not as a result from this live August 25 selection.

This release changes presentation only. It does not change ontology, RML,
SHACL or source acquisition, and does not require a serving rebuild. An
unavailable result still indicates that the selected evidence and implemented
data path do not yet support that result; the definition of the measure is
separate from its current data coverage.
