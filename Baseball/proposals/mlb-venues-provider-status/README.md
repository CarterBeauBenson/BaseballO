# MLB venue provider status

Status: **under review — design only**

This package isolates the meaning of MLB venue 'active'. The conservative
answer is that it describes provider resource availability or status, not
physical existence, operational readiness, closure, demolition, or a timeless
Venue quality.

Because the value has no demonstrated research use, the proposed disposition
is to retain it only in acquisition/provenance metadata or exclude it. The
field already occurs in the MLB game payload. No ontology class is proposed.
