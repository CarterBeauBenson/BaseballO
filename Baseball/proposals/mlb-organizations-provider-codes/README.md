# MLB organization provider codes

Status: **under review — design only**

This package asks which team, league, and division code fields are genuine
Code Identifiers, which Organization they designate, and which provider
Reference System gives each code its meaning. Equal lexical codes from
different systems do not identify one Code Identifier.

The fields already occur in the MLB game payload when present. This review
proposes provider Reference System individuals only as future data-model
instances, not ontology universals, and authorizes no executable artifacts.
