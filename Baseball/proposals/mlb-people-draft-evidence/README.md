# MLB people draft evidence

Status: **under review — design only**

This package asks what 'draftYear' can support. A year does not identify a
draft Act, its selecting Organization, the selected Person relation, a round,
a pick, or a resulting contract/employment act.

The field already occurs in the MLB game payload. The conservative proposal is
information-only Temporal Interval Identifier evidence until a richer source establishes a
particular draft Process/Act structure. No field-specific ICE or property is
proposed.
