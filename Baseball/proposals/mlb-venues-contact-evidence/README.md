# MLB venue contact evidence

Status: **under review — design only**

This package isolates the venue 'phone' field from address and geographic
semantics. It first asks whether a telephone contact identifier has a concrete
research or operational DSQ. Without one, the proposed disposition is to
exclude it rather than expand the ontology for unused provider metadata.

If admitted later, the telephone number would be information that designates a
telecommunication endpoint or contact channel under a reviewed numbering
system; it would not be a literal intrinsic property of the physical Venue.
