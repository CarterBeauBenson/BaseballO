# Source evidence

The archived accepted Statcast review records official MLB documentation that
`arm_angle` concerns the line from the pitcher's shoulder to the Baseball at
release relative to the ground. The accepted field inventory marks it
genuinely additional. This package does not reopen that classification and
does not select duplicate release position, speed, acceleration, person, or
pitch fields.

The current ontology supplies Person, generic Bodily Component, Baseball,
Pitch Act, Pitch-Ball Motion Process, Velocity, Process Profile, Fiat Point,
Fiat Line, Angle Quality, Measurement ICE, Degree, Baseball Field Coordinate
Reference System ICE, Temporal Region, and their existing relations.

There is no current accepted Shoulder class or reviewed source rule selecting
the anatomical point used by Statcast. The provider's exact ball reference
point, ground-parallel line, release evaluation, and method history also remain
unresolved. Generic world individuals can be shown in the design, but their
identity cannot be supplied by labels or field-shaped ICE subclasses.

The Pitch-Ball Motion Process already has a Baseball participant in the
accepted model. The new Process Profile foundation supports a Velocity as an
occurrent part of that motion only where direction and frame are represented.
Arm angle remains a measurement of relational geometry; it is not a velocity
measurement.
