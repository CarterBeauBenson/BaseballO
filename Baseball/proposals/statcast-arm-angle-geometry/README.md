# Statcast arm-angle geometry

Status: **under review — design only**

This package isolates Statcast `arm_angle`, which the accepted inventory marks
genuinely additional. The reported number is not an `ArmAngle` ICE standing in
for reality. The candidate target is an accepted Angle Quality inhering in two
actual Fiat Lines that share a Fiat Point at a release-local part of the
Pitch-Ball Motion Process.

The package also applies the Process Profile guidance: the changing ball motion
has a Velocity Process Profile as an occurrent part, while the arm-angle
measurement targets release-local geometry. The review must decide how a
provider-defined release evaluation, motion segment/profile, ball reference
point, shoulder landmark, and ground reference are connected. Those semantics
may not be hidden in the word `release`.

The schema key `sourceIndependentMermaid` points to this package's
`source-specific-mermaid.md`. No class, property, ontology edit, mapping, or
graph execution is proposed.
