# Decisions needed

| ID | Question | Decision options |
| --- | --- | --- |
| ELEVATION-01 | Does the value measure CCO Altitude? | Yes only if it is height relative to Earth surface or mean sea level, consistent with the accepted CCO definition. |
| ELEVATION-02 | Which Site bears the Altitude? | Field reference Site/Point, entire venue Site, or another provider-defined target. |
| ELEVATION-03 | Which unit applies? | Require explicit source evidence for Foot, Metre, or another unit; stadium dimension units do not prove elevation units. |
| ELEVATION-04 | Which vertical datum applies? | Mean sea level, ellipsoid, ground surface, or another datum must be identified. |
| ELEVATION-05 | Does the source evidence a measurement Process? | No; emit at most a Measurement ICE about Altitude. |
