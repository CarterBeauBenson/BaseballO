# Field inventory and de-duplication

| Field/evidence | Disposition | Consequence |
| --- | --- | --- |
| `firstYearOfPlay` | authoritative duplicate; information-only candidate | At most identify a Year after reference-system review. |
| Organization resource ID | identity/join-only | Does not bind the Year to a founding Process. |
| authoritative Game history | richer RDF/derived | Candidate basis for first observed qualifying Game. |
| retrieval time/hash | provenance | Does not create a validity interval. |
| null/malformed year | absence or invalid input | Null emits nothing; malformed present values fail validation if admitted. |

No founding or debut class is proposed. A separately evidenced institutional-
history Process would require its own review package.
