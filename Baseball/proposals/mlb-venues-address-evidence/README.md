# MLB venue address evidence

Status: **under review — design only**

This package asks whether venue address component strings form an Address
Information Content Entity that designates a delivery/location Site and how
city, administrative-region, postal-code, and country referents are identified.
Equal or normalized strings do not establish geographic identity.

The fields already occur in the MLB game payload. This package authorizes no
ontology, mapping, or source-ownership cutover.
