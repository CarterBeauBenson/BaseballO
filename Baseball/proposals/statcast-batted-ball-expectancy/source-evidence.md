# Source evidence

The archived accepted Statcast review records MLB documentation for xBA and
xwOBA:

- xBA assigns a likelihood from comparable batted balls;
- beginning in 2019, seasonal sprint speed contributes for some topped or
  weakly hit balls;
- xwOBA uses probabilities for multiple hit types and season-adjusted wOBA
  outcome weights; and
- sprint speed also enters some batted-ball types beginning in 2019.

This evidence defeats a naive interpretation of either output as a timeless
two-input formula based only on launch speed and launch angle.

The accepted inventory marks both fields genuinely additional. MLB-game owns
the canonical batted-ball motion, launch measurements, actual result, player,
and game facts. Statcast may join to those identities but may not remap the
duplicate facts.

Existing vocabulary supplies generic Process, Algorithm, Act of Data Transformation,
Probability Measurement ICE, Estimate ICE, Point Estimate ICE, generic
Measurement ICE, `has input`, `has output`, `prescribed by`, `is about`, `is a
measurement of`, and direct decimal values. BaseballO supplies Batted-Ball
Motion Process and actual institutional outcome processes such as Hit Process.

The missing semantic anchor is a reviewed possible/model outcome target. The
actual Hit Process class cannot type a merely possible hit without claiming it
occurred. The source also does not expose the complete xwOBA outcome
distribution or all versioned Algorithm inputs in these two scalar columns.

A model output supports the existence of some computation Process. The current
evidence does not identify a causally active Agent at that Process's grain, so
the source-specific shape does not yet type it as an Act of Data
Transformation.
