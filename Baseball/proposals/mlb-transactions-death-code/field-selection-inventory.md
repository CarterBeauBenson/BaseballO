# Field inventory and de-duplication

| Field/evidence | Disposition | Consequence |
| --- | --- | --- |
| exact Death `typeCode`/`typeDesc` | genuinely additional; accepted candidate | Require pinned exact match. |
| `person.id` | identity/join-only; required | Absence blocks world-side Death mapping. |
| `effectiveDate`/`date` | temporal evidence | May designate a Day; not an invented exact instant or universal role boundary. |
| Team mentions | irrelevant to Death identity | Do not infer agency or membership. |
| description | unstructured evidence | Do not parse into new assertions. |

No class or property gap exists. Boundary consequence: none is authorized for
Player Role stints by this code alone.
