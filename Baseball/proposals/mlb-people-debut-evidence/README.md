# MLB people debut evidence

Status: **under review — design only**

This package asks whether an MLB debut is a new Act universal or a derived
description of the earliest qualifying participation in an existing Baseball
Game. A date alone cannot identify that Game or an exact Process boundary.

The field already occurs in the authoritative MLB game payload. The proposed
direction is to derive debut from persistent authoritative Game RDF after
competition and participation criteria are accepted, using the provider date
as equivalence evidence rather than a duplicate world assertion.
