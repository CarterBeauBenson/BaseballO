# Source evidence

The accepted people inventories show 'mlbDebutDate' in both the standalone
people endpoint and MLB game person object. It is therefore an authoritative
duplicate, not new source semantics.

BaseballO supplies Baseball Game, Person, Player Role, Calendar Date Identifier,
and Day. The person field does not supply a debut Game identifier. Historical
authoritative Game RDF can answer an earliest-participation query only after
Major League scope and participation criteria are reviewed. No raw response
was acquired or retained.
