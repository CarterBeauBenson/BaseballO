# Canonical Day authority

Status: **accepted 2026-08-30 - source-independent design**

This package records the approved source-neutral Day identity and daily graph
policy. It reuses CCO Day and Calendar Date Identifier and proposes no new
ontology term. Source identifiers may designate the same Day only when entity
resolution establishes the same temporal extent. Provenance remains attached
to the identifying ICE and graph product, not to the Day's identity.

The daily named graph is an operational RDF container, not a domain entity.
It may contain date-bounded Processes and Stases while persistent Persons,
Teams, Venues, Leagues, and Divisions remain in their authority products.
