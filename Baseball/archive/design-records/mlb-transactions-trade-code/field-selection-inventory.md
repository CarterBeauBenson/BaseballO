# Field inventory

| Evidence | Disposition | Consequence |
| --- | --- | --- |
| exact Trade code and accepted group ID | additional world-act evidence | Group validated legs into one Trade Act. |
| Person ID | identity/join-only | Required participant and Role bearer. |
| structured from/to Team IDs | agent and direction evidence | Required for origin/destination agency and Role contexts. |
| effective date | Day evidence | Localizes separate Loss/Gain regions within canonical Day. |
| description | unstructured | Preserve; do not parse. |

Loss affects the old team Player Role and precedes Gain affecting the new team
Player Role. Each transition occupies its own Temporal Region.
