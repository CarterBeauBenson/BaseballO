# Field inventory

| Evidence | Disposition | Consequence |
| --- | --- | --- |
| DFA/Waiver/Suspension code | information classification | No Process or temporary Role until independently grounded. |
| Status Change/Acquired/Obtained code | unresolved provider classification | Information-only. |
| Person/Team IDs | identity/aboutness | Link record to canonical entities without inferring agency or movement. |
| effective/resolution date | Day evidence | Preserve field identity and designated canonical Day. |
| description | unstructured | Preserve; do not parse. |

No team Player Role boundary or temporary status Role is emitted in the first
RML pass.
