# Source evidence

The source code list includes Designated for Assignment, Waiver, Suspension,
Status Change, Acquired, and Obtained. These labels do not identify one shared
Process kind and do not independently ground the realization or identity of a
temporary status Role.

The first RML pass therefore preserves information classification, canonical
aboutness, and date evidence only. Later world mapping requires a separately
reviewed exact-code package with causal Agent, Process differentia, Role
identity where applicable, and temporal consequences. No raw response is
retained.
