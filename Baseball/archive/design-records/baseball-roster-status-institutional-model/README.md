# Baseball roster-status institutional model

Status: **accepted 2026-08-30 - source-independent design**

This package proposes only roster-status Acts whose differentiae have an
independent world-side anchor. It does not create one class per MLB transaction
code. Assigned, Recalled, Optioned, Outrighted, Selected, Status Change,
Acquired, Obtained, DFA, Waiver, and Suspension remain information-only in the
first RML pass unless a separate proposal grounds their exact Process or Role.

The proposed Release, Free Agency Declaration, and Retirement Declaration Acts
are distinct from the descriptive MLB transaction record and from their output
Directive ICEs. Each precedes only the exact Gain or Loss of Role supported by
the evidence.
