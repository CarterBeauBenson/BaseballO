# MLB-game postponement proposal

Review-only proposal for representing an official change to the planned time of
one Baseball Game without minting a second Game from a second schedule row.

The proposal introduces two candidate classes:

- `BaseballGameSchedulePlan`
- `BaseballGamePostponementAct`

It introduces no object or data properties. The official MLB postponement
reason remains generic Nominal Measurement ICE content. Delay,
suspension/resumption, and cancellation are explicitly outside this package.

No ontology, RML, SHACL, NiFi, authoritative RDF, query, SQL, or UI artifact is
authorized by this under-review package.
