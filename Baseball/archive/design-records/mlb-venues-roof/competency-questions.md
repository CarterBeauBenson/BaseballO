# Competency questions

| ID | Question | Candidate answer |
| --- | --- | --- |
| ROOF-01 | What does a roof-present type classify? | A Baseball Venue Roof: a Material Artifact and continuant part of the Venue. |
| ROOF-02 | Why can it cover the Venue? | The roof bears CCO Covering Artifact Function by virtue of its design. |
| ROOF-03 | What does `retractable` establish? | A design classification only. It does not establish an open/closed position or a realization at retrieval time. |
| ROOF-04 | What does an open-air/no-roof code do? | Preserve configuration information about the Venue without creating a roof artifact or interpreting `open` as a current state. |
| ROOF-05 | How are changes handled? | Response-version evidence. Do not invent installation, removal, movement, or configuration intervals. |

## Negative tests

- A roof-type ICE is not a roof artifact or Artifact Function.
- A retractable roof is not asserted open or closed without time-specific evidence.
- An open-air code does not mint a roof.
- Retrieval season does not establish a season-long roof state.
