# MLB venue roof artifact

Status: **accepted 2026-08-30 — source-independent design**

A baseball-venue roof is a real Material Artifact that is a continuant part of
the Baseball Venue and bears CCO's existing Covering Artifact Function. The
function exists by virtue of design and may remain unrealized. A retractable
design classification does not assert the roof's position at a particular
time.

The provider `roofType` value is a Nominal Measurement ICE about the roof when
the code entails that a roof artifact exists. An open-air/no-roof code remains
information about the Venue configuration and does not mint a fictional roof.

This package proposes `BaseballVenueRoof` and no new function or object
property. It authorizes no executable source change.
