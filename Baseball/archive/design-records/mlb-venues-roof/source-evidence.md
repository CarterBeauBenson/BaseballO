# Source evidence

The accepted venue contracts list `fieldInfo.roofType` in both venue and game
payloads. The ontologist established that a supported roof is a material part
of the Venue and bears an Artifact Function. CCO already supplies Covering
Artifact Function, so no field-shaped function class is needed.

The source type value can support a roof artifact only for codes whose pinned
meaning entails roof presence. Open-air/no-roof values cannot create a roof,
and no type value alone establishes an open/closed position at a particular
time.

The payload does not identify installation, removal, movement, or state-change
Processes. No raw response was retained for this proposal.
