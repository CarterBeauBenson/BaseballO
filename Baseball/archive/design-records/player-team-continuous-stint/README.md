# Player-Team continuous stint

Status: **accepted 2026-08-30 - source-independent design**

One particular Player Role inheres in a Person for one uninterrupted stint
with one Baseball Team as organizational context. Gain and Loss Processes
affect that exact Role when boundaries are evidenced; the intervening Stasis
contains the persistence interval and never realizes the Role. Left-censored
and open histories omit invented transitions. Cross-source reconciliation
occurs only after independent source promotion.
