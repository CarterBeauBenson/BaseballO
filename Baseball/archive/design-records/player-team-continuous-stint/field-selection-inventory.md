# Field and identity inventory

| Evidence | Classification | Candidate use |
| --- | --- | --- |
| canonical Person and Team IDs | identity/join-only | Identify bearer and organizational context. |
| game roster occurrence | existing game-scoped evidence | Supports game participation/realization, not a stint boundary. |
| exact transaction code plus structured direction | genuinely additional boundary evidence | May support Gain/Loss only under an accepted code contract. |
| effective/resolution date | Day evidence | Calendar Date Identifier designates canonical Day; a supported transition region may be temporal part of it. |
| missing observation | absence of evidence | Never ends a Role. |
| description | unstructured evidence | Preserve; never parse into a boundary. |

Player Role identity is Person + Team + uninterrupted-stint boundary. A
left-censored Role keys from the earliest supported Stasis boundary without an
invented Gain. Cross-source history is derived after independent promotion.
