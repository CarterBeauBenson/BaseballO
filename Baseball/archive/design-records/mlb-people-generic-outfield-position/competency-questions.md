# Competency questions

1. What does MLB people primary-position code `O` describe?
2. Which existing realist entities does that description concern?
3. Does the code establish an exclusive outfield-only kind or Role?

## Accepted answers

Code `O` is a reusable MLB nominal description of a generic Outfield position.
For one Person record it describes the Person, that Person's career-persistent
Fielder Role, and a Baseball Fielding Disposition. When the same record supplies
a throwing-side value, the description may also be about the accepted Throwing
Side Disposition. It does not create an Outfielder Role, assert exclusivity, or
preclude the Person from also playing infield.
