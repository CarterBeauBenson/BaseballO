# Source evidence

The source code list includes Assigned, Recalled, Optioned, Outrighted, and
Selected. Their provider labels establish distinct nominal classifications but
do not establish source-independent Process differentiae, temporary Role
identity, or team Player Role consequences.

The first RML pass therefore preserves the record, exact code measurement,
canonical Person/Team aboutness, and field-distinct Day evidence. It does not
create a world Act or Role transition. No raw response is retained.
