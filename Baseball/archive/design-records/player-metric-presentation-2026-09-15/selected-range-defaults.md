# Selected-range defaults accepted September 15, 2026

The user clarified:

> Tje default for everything should be averages for the selected timespan,
> with the exception of empty games, which is a game count.
>
> We can consider how to show single game highs for some timespan, or yearly totals

Default player summaries use averages over eligible observations within the
selected timespan. The Empty Games headline is a count of qualifying empty
games in that timespan. It must not display an empty-game percentage as a
count or recover a count from a reduced fraction. Existing qualification and
complete-evidence requirements continue to apply.

The previously accepted PA, run, defensive, and affected-player attribution
rules continue to determine the observations being summarized. Existing rate
formulas retain their eligible-event denominators; a percentage is the mean
of the corresponding event indicator. This direction does not authorize
averaging daily percentages without their denominators.

Single-game highs and yearly totals are future presentation possibilities,
not current defaults or a request to implement new views. This supersedes the
earlier suggestion to expose batting totals automatically in the expanded view.
Role breadth remains backend-only. No vocabulary, source mapping, identity,
semantic-freeze change, or fabricated score population is authorized.
