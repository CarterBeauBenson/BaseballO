  2026, by 13:14:40 UTC. Games 823327, 823489, 824301, 824302 and 824866 each
  received three missing triples: the compound result's Double Play type and
  its two existing Out Process parts. Existing RDF was preserved. Retired

- **Overlapping regions:** PA admission preserves overlapping header clocks
  and their diagnostics. Independently reconciled half histories can support
  state boundaries without forcing temporal regions to be disjoint. Unknown
  transitions, failed graph constraints and invalid individual intervals still
  block their affected calculations. NiFi refreshes older overlap-only failures.
- **Explicit strategy:** the SPARQL evidence query reads the existing result
  description and compound out membership. The calculator accepts explicit
  affirmative hit-and-run wording only with the two reconciled movement
  participants. It also recognizes explicit straight/independent-steal wording.
  A K/CS pair, silence, negation or conflicting text does not confirm either
  strategy. No strategy entity, class or object property is introduced.
- **Shared erosion:** confirmed independent outs use one actual end state and
  each channel's own out count in the existing exact kernel. The approved
  first/third, one-out example yields batter damage 3/4 and runner damage 5/6.
  Confirmed failed hit-and-run still charges 19/12 to the batter, with no
  duplicate running observation. Independent damage also enters Empty Game
  Damage through the runner's negative contribution score.

The SQL version transition rereads only games containing compound Double Play
results. Unchanged game evidence, calculations and player partitions are
reused. Dashboard requests continue reading prepared SQL.

Focused checks cover the real K1 selection and additive graph constraints,
overlap admission without loss of history constraints, attribution arithmetic,

not establish complete season coverage. Strategies not explicitly evidenced,
unresolved histories, other mapping coverage debt and incomplete reference
