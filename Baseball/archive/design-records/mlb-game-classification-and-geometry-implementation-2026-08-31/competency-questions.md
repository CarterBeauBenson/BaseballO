# Competency questions

The accepted implementation must support these questions without crossing the
reviewed semantic boundaries:

1. What is the currently authoritative pitch classification for a Pitch Act?
2. What nominal-classification evidence supports that current classification?
3. What is the currently authoritative trajectory classification for a
   Batted-Ball Motion Process?
4. In which Baseball Season Segment or Phase did a Baseball Game occur?
5. Which transaction Acts occupy Temporal Intervals within a named Baseball
   Transaction Period?
6. Which Site is the rule-book Baseball Strike Zone, and which Fiat Surface is
   an ABS evaluation plane?
7. Can historical classification evidence be preserved without causing a
   reclassified entity to infer every historical subtype? The required answer
   is yes: subtype inference is confined to the rebuildable current-state
   graph.
8. Can a provider coordinate mint a world-side batted-ball Site before its
   reference frame is grounded? The required answer is no.
