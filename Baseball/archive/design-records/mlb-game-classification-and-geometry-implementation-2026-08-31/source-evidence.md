# Source evidence

This record does not add source evidence. It incorporates the hash-pinned
evidence in the accepted archived records for:

- `baseball-pitch-and-batted-ball-classifications`;
- `baseball-season-and-transaction-periods`; and
- `baseball-strike-zone-geometry`.

The MLB Games `feed/live` payload remains the owning source for the mapped
classification and season-phase evidence. Provider labels are nominal
measurement evidence interpreted under a versioned provider Reference System.
The authoritative RDF remains persistent; the explicit current subtype is a
rebuildable indexed assertion.
