# MLB-game classification, state, and phase decisions — 2026-08-31

Status: **accepted**

This record captures the ontologist's explicit decisions concerning pitch-type
classification, pitch-event identifiers, generated out counts, provider code
handling, replay output persistence, strike-zone structure, and season
segments. It records the accepted design boundary before implementation.

It does not approve exact new class IRIs or definitions. Pitch-type-specific
Pitch Act classes, strike-zone classes, and season-segment classes still
require their own proposal artifacts before ontology implementation. The
provider-display coordinate question is deliberately excluded because its
revised Cartesian pattern still awaits confirmation.
