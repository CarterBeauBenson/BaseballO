# NiFi control-plane hardening

Accepted on 2026-09-01 after the failed MLB Teams authority run exposed a
repeated class of orchestration defects. This record separates configuration
reconciliation, graph-promotion validity, consumer compatibility, and durable
dependency dispatch.

The quarantined Teams run remains failure evidence. Acceptance of this design
does not authorize its mutation or automatic retry.

## Authority boundary

The ontologist controls semantic meaning and the major lifecycle topology. The
accepted lifecycle is `API -> RML -> SHACL -> Fuseki -> queries -> SQL -> UI`.
Within that accepted shape, processor mechanics, locks, retries, manifests,
fingerprints, physical indexes, SQL implementation, tests, and UI plumbing are
engineering decisions and do not require path-by-path ontologist approval.
