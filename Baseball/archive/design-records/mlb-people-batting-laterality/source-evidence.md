# Source evidence

The accepted people gap review records person-level 'batSide' values 'L', 'R',
and 'S'. It also establishes that the same field occurs in the authoritative
MLB game payload and that a particular Plate Appearance's observed matchup
side is not identical to a persistent capability.

Existing accepted vocabulary includes Person, Batter Act, Home Plate,
Disposition, realization relations, and generic Nominal Measurement ICE with
a Reference System. The ontologist selected a real disposition borne by the
Person as the target. Left and right observations support distinct particular
dispositions; switch evidence supports both.

The API code does not identify an actual Batter Act or a complete disposition
history. It therefore supports the bearer and nominal side of each disposition
without inventing realization events or beginning and ending boundaries. No
raw JSON was retained for this design package.
