# Counts have no appearance minimum

On October 1, 2026, Carter Beau Benson clarified:

> especially count totals liek Empty Games. Every player should be included.
> The appearance limits only count for rates

Count leaderboards must include every player with a supported applicable total,
including zero totals and players below the batting or other participation
minimums. Empty Games is the current public count metric. Remove its 3.1 PA
per team-game cutoff; do not apply an alternative minimum game count.

Retain the accepted participation minimums for rates and averages. Existing
per-game Empty Game eligibility still determines which games enter the count.
Unknown counts are not zero, and unresolved records remain a separately
disclosed coverage issue rather than a failure to qualify by appearances.

This changes presentation qualification only. It requires no ontology change,
RML change, RDF rebuild, SQL metric recalculation or source acquisition. Apply
the rule to prepared SQL results in both dashboard cards and expanded details.
This decision is published before implementation.
