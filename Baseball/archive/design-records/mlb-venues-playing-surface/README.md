# MLB venue playing-surface artifact

Status: **accepted 2026-08-30 — source-independent design**

The playing surface is a real Material Artifact that is a continuant part of
the Baseball Venue. It is not identical to the Baseball Field Site. Its design
grounds a Structural Support Artifact Function realized when it physically
supports players, the Baseball, and other participants in baseball Processes.

The provider `turfType` classification is a Nominal Measurement ICE about that
artifact. Replacement creates a new surface particular. Because the endpoint
does not supply installation or replacement boundaries, its response-scoped
evidence does not assert a timeless surface identity or invented Stasis.

This package proposes `BaseballPlayingSurface` and no object property. It
authorizes no executable source change.
