# Source evidence

The accepted venue reviews observed `fieldInfo.turfType` in the standalone
venue endpoint and MLB game payload. The ontologist established that the
classified target is a material part of the Venue and that the part bears an
Artifact Function. The selected accepted function parent is CCO Structural
Support Artifact Function.

BaseballO supplies Baseball Venue and Baseball Field Site. BFO/CCO supplies
Material Artifact, Artifact Function, continuant parthood, Nominal Measurement
ICE, and Reference System. No new object property is required.

The payload does not identify a surface installation or replacement Process,
effective interval, or exact material composition beyond its provider label.
No raw API bytes were retained for this proposal.
