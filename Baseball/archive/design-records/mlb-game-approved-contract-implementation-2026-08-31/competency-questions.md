# Competency questions

This record aggregates the already accepted MLB-game contract into one implementation boundary.

- Can the authoritative graph preserve source evidence without making superseded nominal classifications participate in current class inference?
- Can season phase, pitch type, trajectory, pitch-call, and runner-event questions be answered from reviewed world-side structures or a rebuildable index derived from them?
- Can routine Explorer and serving queries stop depending on provider routing literals while retaining the authoritative RDF as the source of truth?
- Can NiFi run RML, source SHACL, query-index equivalence, and serving materialization as one gated lifecycle?
