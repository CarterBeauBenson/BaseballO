# MLB transaction release and retirement codes

Status: **accepted 2026-08-30 - source-independent design**

Release, free-agency declaration, automatic free-agency acquisition, and
retirement are distinct. A supported Baseball Player Release Act has Team
agency, a release-decision output, and precedes Loss of an exact team Player
Role. Free agency requires independent evidence. A Retirement Declaration Act
ends only the exact active Role supported by the source.
