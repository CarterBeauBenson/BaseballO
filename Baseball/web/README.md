# Web

Reserved for the future GitHub Pages interface that will expose reviewed canned SPARQL queries without requiring users to write SPARQL.

The UI-facing query components and allowlisted compilers are documented in
[`query-builder/`](query-builder/README.md). The general analytics compiler
covers batting, pitching, baserunning, games, teams, venues, and officials. The
components are framework-independent so a later interface can populate select
boxes directly from the exported catalogs.
