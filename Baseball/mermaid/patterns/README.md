# Implemented RML event-pattern catalog

This catalog documents the RDF graph generated by the active direct RML in mappings/direct/mlb-direct.rml.ttl. The RML was changed first; these diagrams reflect the implemented mapping rather than a proposed target model.

Each solid arrow is an emitted RDF relation. Dashed arrows indicate a source limitation, a conditional branch, or a relation deliberately not asserted. Success and failure are never act classes: intentional acts remain neutral and materially different downstream physical or counted outcomes receive separate diagrams.

The catalog distinguishes exact RML variants. Called and swinging strikes are separate because only the called strike produces a StrikeCallAct. Foul and foul tip are separate because a foul may produce a distinct counted strike, while one foul-tip individual is typed as both FoulTipProcess and StrikeProcess. Runner out, safe, run, and stolen-base patterns are separate because they produce different judgments, decisions, artifacts, and counted processes.
